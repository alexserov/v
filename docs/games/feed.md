# Покорми зверят (`feed`)

**Тайл:** 🥕 · градиент `#ffc2dd → #ff7fb6`
**Жанр:** забота / выбор
**Цель:** кормить зверят.

## Сцена

Пикник: 2–3 зверя и поднос с едой — морковка, яблоко, ягода, брокколи, мёд.

## Игровой цикл

- Тап по еде → она подсвечивается и приподнимается.
- Тап по зверю → еда летит к нему, зверь ест и радуется (сердечки, «ням»).
- Любимая еда вызывает восторг, остальная тоже съедается — но спокойнее.
- Поднос пополняется, периодически приходит новый гость.

## Управление

Два тапа: еда → зверь. Выбор еды можно менять.

## Без проигрыша

Никто не отказывается и не грустит, еда не пропадает зря.

## Отклик

«Ням», сердечки, довольные мордочки, счётчик угощений сверху.

## Технически

Canvas (`CanvasGame`), состояния idle → selected → flying → eating,
частицы-сердечки.

## Критерии готовности

- Можно выбрать еду и покормить зверя.
- Реакция зверя и звук.
- Бесконечный цикл, новые гости.
- Mute работает, ошибок нет.
