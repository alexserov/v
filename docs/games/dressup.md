# Одень зайчика (`dressup`)

**Тайл:** 🎀 · градиент `#ffb3d9 → #9b7bff`
**Жанр:** творчество / наряды
**Цель:** свободно наряжать персонажа.

## Сцена

Большой зайчик на мягкой сцене. Внизу категории: шапочки, шарфики,
очки, бантики. Кнопка «сюрприз» надевает случайный комплект.

## Игровой цикл

- Тап по категории → показывается ряд предметов.
- Тап по предмету → надеть/снять.
- Зайчик моргает, шевелит ушами, улыбается.
- Никакой цели: свободная игра и бесконечные комбинации.

## Управление

Крупные кнопки категорий и предметов.

## Без проигрыша

Любой образ хорош. Ничего нельзя испортить.

## Отклик

Предмет «влетает» с пружинкой, искры, звук, реакция персонажа.

## Технически

Canvas-персонаж (`CanvasGame` или отдельный canvas) + DOM-панель
с крупными кнопками. Предметы рисуются кодом.

## Критерии готовности

- 4 категории и несколько предметов в каждой.
- Надевание/снятие работает.
- Персонаж реагирует.
- Mute работает, ошибок нет.
