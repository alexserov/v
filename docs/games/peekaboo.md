# Найди зверюшку (`peekaboo`)

**Тайл:** 🐾 · градиент `#a8e6a1 → #4caf50`
**Жанр:** прятки / наблюдательность
**Цель:** найти именно того зверька, который показан в карточке цели.

## Сцена

Полянка с 5 кустами. За ними прячутся разные зверята. Сверху по центру —
карточка цели: круглая плашка с мордочкой нужного зверька и значком 🔍.

## Игровой цикл

- В начале раунда игра показывает, **кого ищем** (карточка цели).
- Один из кустов прячет целевого зверька, остальные — других.
- Тап по правильному кусту → зверёк выбирается, карточка получает ✅,
  летят сердечки и искры, звучит праздничный аккорд. Через ~1,8 с —
  новый раунд с новой целью.
- Тап по неправильному кусту → зверёк **выглядывает из куста, машет
  лапкой и прячется обратно**. Карточка цели мягко качается, играет
  тихий «не тут». Без штрафа.

## Управление

Тап по кусту (крупная зона).

## Без проигрыша

Неправильный выбор — это милая реакция, а не ошибка. Можно пробовать
сколько угодно раз.

## Отклик

Карточка цели, выглядывание, машущая лапка, сердечки, искры, мягкие
звуки, ✅ при успехе.

## Технически

- Canvas (`CanvasGame`) для полянки, кустов и анимаций.
- DOM-карточка `.peekaboo-target` с мини-canvas, учитывает safe-area.
- Анимация выглядывания: `peek` 0→1→0, лапка качается синусоидально.
- 14 видов зверят из общего арта (`src/art/characters.ts`).

## Критерии готовности

- Карточка цели показывает нужного зверька и обновляется каждый раунд.
- Неправильный куст: выглядывание + взмах лапкой + возврат.
- Правильный куст: зверёк найден, ✅, новый раунд.
- 14 видов зверят; Mute работает; ошибок нет.
