# Раскраска (`coloring`)

**Тайл:** 🎨 · градиент `#ffd36e → #ff6f91`
**Жанр:** творчество
**Цель:** раскрашивать картинки.

## Сцена

Контурная картинка (зайчик, мишутка, цветок, машинка, рыбка, домик)
и палитра из 8–10 цветов внизу.

## Игровой цикл

- Тап по цвету → выбран.
- Тап по области → заливка выбранным цветом.
- Когда все области закрашены — картинка «оживает» (анимация, звёздочки)
  и загружается следующая.

## Управление

Два тапа: цвет → область. Крупные зоны.

## Без проигрыша

Любой цвет и любая область. Промах игнорируется.

## Отклик

Всплеск краски, «поп» заливки, праздник и смена картинки.

## Технически

Canvas, картинки как набор векторных областей (`Path2D`),
попадание через `isPointInPath`, карта заливок, контуры сверху.

## Критерии готовности

- Выбор цвета и заливка области.
- Несколько картинок, смена после завершения.
- Праздничная анимация.
- Mute работает, ошибок нет.
