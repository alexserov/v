# Пузырики (`bubbles`)

**Тайл:** 🫧 · градиент `#a0e7ff → #5aa9ff`
**Жанр:** реакция / тап
**Цель:** лопать пузыри — бесконечно и спокойно.

## Сцена

Мягкая полянка: небо-градиент, солнце, облака, трава. Снизу поднимаются
пузыри разного размера. В некоторых пузырях — мордочки зверят.

## Игровой цикл

- Пузыри появляются снизу и плавно поднимаются с лёгким покачиванием.
- Тап по пузырю → он лопается: искры, звук «поп» (тон зависит от размера).
- Если внутри был зверёк — он улетает и машет.
- Улетевший вверх пузырь тихо лопается, вместо него появляется новый.
- Счётчик лопнутых пузырей — сверху по центру.

## Параметры

- Размер 40–90 px, на экране 10–12 штук.
- Спавн каждые 0,4–0,9 с.
- Подъём 20–60 px/с, покачивание по горизонтали.

## Управление

Тап по пузырю. Hit-тест по кругу с запасом.

## Без проигрыша

Тап мимо — просто ничего не происходит.

## Отклик

Искры, «поп», улыбки зверят, лёгкое покачивание.

## Технически

Canvas (`CanvasGame`), простые частицы (`Particles`), звук `sound.pop(size)`.

## Критерии готовности

- Тап лопает пузырь.
- Внутри встречаются зверята.
- Бесконечный спавн и замена улетевших.
- Mute работает.
- 60 fps на телефоне, без ошибок в консоли.
