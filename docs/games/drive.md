# Покатушки (`drive`)

**Тайл:** 🚗 · градиент `#8fe3c8 → #2fb38a`
**Жанр:** движение / сбор
**Цель:** бесконечная милая поездка.

## Сцена

Машинка со зверьком за рулём, дорога, параллакс: холмы, деревья, облака.
По дороге — звёздочки и лужи.

## Игровой цикл

- Тап в любом месте → машинка плавно едет к этой точке по горизонтали.
- Звёздочки собираются: искры, счётчик, звук.
- Лужи дают брызги, но без штрафа.
- Скорость мягко растёт и стабилизируется.

## Управление

Тап в любом месте дороги — очень интуитивно для малыша.

## Без проигрыша

Нет столкновений-наказаний. Лужа — просто весёлый всплеск.

## Отклик

Сбор звезды, всплеск, покачивание машинки, звуки.

## Технически

Canvas (`CanvasGame`), параллакс, плавное следование за целью,
hit-тест звёзд по кругу.

## Критерии готовности

- Тап рулит машинкой.
- Звёзды собираются и считаются.
- Бесконечная дорога, лёгкая прогрессия скорости.
- Mute работает, ошибок нет.
