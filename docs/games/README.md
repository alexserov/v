# Игры «Мини-игр»

Сборник бесконечных мини-игр для ребёнка 3 лет. Управление — крупный тап,
без проигрыша и без текста.

## Общие принципы

- Только тап (максимум — простой свайп). Крупные зоны нажатия.
- Никакого проигрыша: ошибка даёт мягкую реакцию, но не наказание.
- Каждое действие — яркий отклик: звук, искры, анимация.
- Бесконечный цикл: предметы/раунды/гости появляются снова.
- Спокойный темп, без таймеров и давления.
- Всё рисуется кодом (Canvas), без внешних ассетов.

## Общий мир

Персонажи: Зайчик, Мишутка, Лисичка, Ёжик, Котёнок, Птичка.
Пастельные цвета, круглые формы, мягкие тени. Общий арт —
`src/art/characters.ts`.

## Общий каркас

- `src/engine/CanvasGame.ts` — цикл, resize/DPR, тапы, очистка.
- `src/engine/particles.ts` — искры/звёздочки/конфетти.
- `src/engine/sound.ts` — синтез звуков через WebAudio.
- `src/ui/hud.ts` — счётчик-пилюля сверху по центру.
- `src/ui/backButton.ts` — «назад» слева сверху.
- `src/ui/soundButton.ts` — звук 🔊/🔇 справа сверху.

## Звук

Синтез без файлов: «поп», колокольчик, ноты, «ням», всплеск.
Громкость низкая, включение после первого тапа. Состояние mute
сохраняется в `localStorage` (`mini-games:muted`).
