# Музыкальная полянка (`music`)

**Тайл:** 🎵 · градиент `#c3a6ff → #7c5cff`
**Жанр:** музыка / свободная игра
**Цель:** свободно играть мелодию.

## Сцена

Полянка, 6 больших цветов-нот внизу, вокруг танцующие зверята.

## Игровой цикл

- Тап по цветку → нота, цветок пружинит, летят лепестки.
- Ближайший зверёк танцует/подпрыгивает.
- Каждый цветок — свой цвет и нота пентатоники.
- Никакой цели: можно играть сколько угодно.

## Управление

Тап по цветку (70–90 px).

## Без проигрыша

Любая нота «правильная».

## Отклик

Мягкий синтезированный звук, анимация цветка, лепестки, танец зверят,
всплывающие нотки.

## Технически

Canvas (`CanvasGame`) + WebAudio (`sound.chime(note)`).
Разблокировка звука по первому тапу.

## Критерии готовности

- 6 нот, приятное звучание.
- Цветы и зверята реагируют.
- Mute работает.
- Ошибок нет, 60 fps.
